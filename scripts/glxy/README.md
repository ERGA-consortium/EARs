# make_EAR Galaxy tool

`make_EAR.xml` and `macros.xml` are a copy of the Galaxy wrapper, kept here for reference. The tool itself lives in [bgruening/galaxytools `tools/ear`](https://github.com/bgruening/galaxytools/tree/master/tools/ear), together with its copy of `scripts/make_EAR.py` and the test data. Change the tool there; this folder doesn't run on its own.
